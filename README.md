# Boiler-Task-Tracker

Project Goal:

Boiler Task Tracker is a Java command-line application that can help students organize assignments, exams, tutoring sessions, and other academic responsibilities. The goal is to make it easier to prioritize tasks and keep track of important deadlines.

MVP Scope:
The MVP will allow users to:
* Add new tasks
* View current tasks
* Mark tasks as completed

Future Plans:
* Task priority levels
* Due-date sorting
* Upcoming deadline reminders

Tech Stack:

* Java
* IntelliJ IDEA
* GitHub
* IO.readln()
* ArrayList
* Java File I/O
